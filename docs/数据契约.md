# 原始资料契约

所有资料均为本地合成。JSONL一行一条来源观察，row_id仅标识该观察；同业务ID可以在不同revision、批次或接收位置出现。未写revision的静态目录按文件给定值解释，不隐含线上查询。事实字段中的None为缺少来源值，不是零或否。

金额字段以minor结尾时为该币种最小单位整数；数量、位置、时间的单位以字段后缀和政策说明为准。日期为ISO日期；绝对时刻携带偏移；原始received字段决定可见性，不能仅按发生日期提前使用资料。后续业务修改以相同格式输入，不限定样本编号。

### registration_contract

op支持sum/count_distinct/add/subtract/multiply/divide；source/field是公开事实字段；args含指标ID或{metric,scope}；where为字段等值合取；scope只能去除声明的筛选和分组，不能移除授权企业范围。注册版本互相引用时固定到本次选定版本，成环拒绝。

### money

人民币分整数；order amount为整单实收基数，line_amount仅为商品行来源声明，不保证相加等于整单金额。商品筛选选择含命中商品的订单集合。退款按最新可见revision，每退款只计一次。

### targets

目标只在企业/活动/月粒度；无日目标或商品分配；不能把全月目标直接与部分天日期过滤比较。不同来源可以在其共有且完整覆盖的维度上比较。目标缺失和目标零分别报告。

### results

除法分母零返回undefined并带原因，缺目标返回unavailable；不能改为0。总计在同授权和筛选范围重新计算。

### delivery

见tools/recipient.py；POST /deliveries接受id,enterprise,content_sha256,body；同id同正文重复返回原回执，同id不同正文409。GET /deliveries/<id>查询已接受事实。服务可接收后断开响应。

### participations

参展记录是企业/活动/月的静态范围目录；没有销售的参展企业仍保留。仅作身份和活动范围依据，不能将其行数或销售订单数互相替代。

## 资料检查

`python -m unittest discover -s tests -v`只检查资料字节与格式，不是尚未开发业务功能的验收。manifest.json中的摘要对应提交内原始字节，收到后续批次应独立登记来历，不修改旧原始记录。
